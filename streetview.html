    If the test fails: what the test link shows, and the fix
    The test link shows…Fix
    Text starting with {"ok":trueThe sheet works. The problem is where the tool is open: use your GitHub Pages link or the downloaded file in Chrome, Edge, Firefox or Safari, not a preview window, and turn off ad-blocking or “shields” for the page.
    A Google sign-in pageAccess isn't Anyone. Deploy › Manage deployments › pencil › Who has access: Anyone (not “Anyone with a Google account”) › Deploy. On a school or work Google account your admin may not allow Anyone; deploy from a personal Gmail account instead.
    “Script function not found: doGet”The deployment is an old version. Paste the code, save, then Deploy › Manage deployments › pencil › Version: New version › Deploy. The /exec link stays the same.
    “Cannot read properties of null” or “isn't attached to a Google Sheet”The script was made at script.google.com instead of from the sheet. Open the Google Sheet › Extensions › Apps Script, paste the code there, and deploy from that project.
    “Authorization is required” or a permissions screenIn the Apps Script editor, pick doGet and click Run once, approve the permissions (Advanced › Go to project if Google warns you), then test again.
    “Sorry, unable to open the file” or a 404The link is wrong or the deployment was archived. Copy the Web app URL again from Deploy › Manage deployments.
    How the audit lead sets this up (once, about 5 minutes)
    1. Create a new Google Sheet. Choose Extensions, then Apps Script.
    2. Delete the sample code, paste the code below, and save.
    3. In the function menu next to Run, pick testSetup and click Run. Approve the permissions (if Google warns the app isn't verified, choose Advanced, then Go to the project). The log should say Connected.
    4. Choose Deploy, then New deployment, type Web app. Set Execute as: Me, and Who has access: Anyone (not “Anyone with a Google account”). Deploy.
    5. Copy the web app URL that ends in /exec and send it to the raters. Each rater pastes it here once.

    Anyone with the URL can add rows, so share it only with your team.
